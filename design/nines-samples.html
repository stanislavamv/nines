How they differ

1 · Full scene

The most atmosphere and the most work. Strongest on the map and the home screen. Heavy for pages you read for a long time.

2 · Dusk grid

Keeps the poster's sky on every page at almost no cost. Text sits on dark panels, so lessons stay readable.

3 · Lantern and ink

The calmest option for long practice sessions. The style lives in components, so it works best for the Code Lab and Drills.

These can be mixed: for example, the full scene on the map, the dusk grid on lessons, and lantern and ink in the Code Lab.
